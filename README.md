# Lee Photowork

Lee Photowork is the personal photography portfolio of Andri Tri Yusmawan. The site presents people-focused work across couples, weddings, families, maternity, and graduation sessions. Its editorial layout keeps the photographs at the center while giving visitors clear paths to browse selected work, understand available sessions, learn about the photographer, and start a conversation through the contact page.

The project is built as a lightweight static website with HTML, SCSS, and vanilla JavaScript. Dart Sass compiles `styles/main.scss` into the production CSS file, while a small JavaScript module handles the responsive navigation and client-side contact-form feedback. The visual system uses local image assets and Google Fonts for DM Serif Display and Manrope. Run `npm install` followed by `npm run build` with Node.js 20.19 or later to compile the stylesheet.
